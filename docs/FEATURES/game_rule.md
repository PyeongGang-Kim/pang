# 게임 룰

## 목표

화면 안의 모든 볼을 제거하면 스테이지 클리어. 목숨이 모두 소진되면 게임오버.

---

## 플레이어

| 항목 | 내용 |
|------|------|
| 이동 | 좌/우 방향키 |
| 공격 | 와이어 샷 — 위쪽으로 수직 발사 |
| 점프 | 불가 |
| 사망 조건 | 볼(크기 무관)에 접촉 시 즉사 |
| 시작 목숨 | 3개 |
| 1UP 조건 | 특정 누적 점수 달성 시 자동 지급 |

### 와이어 샷 제약

- 발사한 와이어가 천장에 닿거나 볼을 처치하기 전까지 재발사 불가.
- 기본 상태에서 동시에 1발만 유지 가능.

---

## 볼 분열

```
Large → Medium → Small → Tiny → 소멸
```

- 볼을 처치하면 한 단계 작은 볼 2개로 분열한다.
- Tiny 볼은 처치 시 완전히 소멸한다.
- 볼이 클수록 높이 튀어오르고 느리게 이동한다.
- 모든 볼은 바닥에서 포물선을 그리며 튀어오른다.

---

## 파워업 아이템

볼 처치 시 일정 확률로 드롭된다.

### 무기 파워업

| 아이템 | 효과 | 중첩 |
|-------|------|------|
| Double Wire | 와이어 2발 동시 발사 | 기본 와이어를 대체 |
| Power Wire | 발사한 와이어가 천장에 고정되어 장벽 역할 | 기본 와이어를 대체 |
| Vulcan Missile | 고속 연사 | 기본 와이어를 대체 |

### 유틸리티 아이템

| 아이템 | 효과 |
|-------|------|
| Force Field | 볼 접촉 1회 무효화 |
| Clock | 볼 이동 일시 정지 |
| Dynamite | 화면 모든 볼을 Tiny 크기로 즉시 축소 |
| Food | 보너스 점수 |

---

## 점수 시스템

- 볼이 작을수록 더 높은 점수를 획득한다.
- 같은 크기의 볼을 연속으로 처치하면 점수 배율(멀티플라이어)이 상승한다.
- 스테이지 클리어 시 남은 시간에 비례한 보너스 점수가 지급된다.

---

## 게임오버

- 목숨 전부 소진 시 게임오버 화면으로 전환.
- 획득 점수가 HI-SCORE를 초과하면 로컬에 저장한다.
- 메인 화면으로 복귀한다.
