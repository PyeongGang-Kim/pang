# 메인 화면

## 화면 구성

게임 실행 시 가장 먼저 표시되는 화면이다.

```
┌─────────────────────────────────┐
│                                 │
│           PANG                  │
│                                 │
│        [ GAME START ]           │
│                                 │
│        [ HI-SCORE ]             │
│                                 │
└─────────────────────────────────┘
```

## 구성 요소

| 요소 | 설명 |
|------|------|
| 타이틀 로고 | "PANG" 텍스트 |
| GAME START | 게임 시작 버튼. 클릭 시 Mission 1 Stage 1-1로 이동 |
| HI-SCORE | 최고 점수 표시 (로컬 저장) |

## 상태 전환

- **GAME START 선택** → Mission 1 Stage 1-1 시작
