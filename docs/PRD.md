# PRD — 팡(Pang)

> 아케이드 게임 구현 사양

---

## 개요

플레이어는 고정 화면 안에서 좌우로 이동하며 위로 와이어를 발사해 풍선(볼)을 모두 제거한다.
점프는 없고, 볼에 닿으면 즉사한다. 단순한 조작이지만 볼의 분열과 개수 증가로 긴장감이 높아진다.

---

## Mission 1 구성

- **배경:** 일본 후지산 (Mt. Fuji)
- **스테이지 수:** 3개 (1-1 / 1-2 / 1-3)
- 3개 스테이지 모두 같은 배경이며 볼 수와 배치가 단계적으로 증가한다.
- 모든 스테이지는 **스크롤 없는 단일 고정 화면**이다.

---

## 핵심 메커니즘

### 볼 분열
볼은 4단계 크기로 분열하며, 마지막 단계(Tiny)를 처치하면 소멸한다.

```
Large → Medium → Small → Tiny → 소멸
```

- 상위 크기 볼 1개를 처치하면 하위 크기 볼 2개로 분열한다.
- 볼이 클수록 더 높이 튀어오르고 느리게 움직인다.
- 모든 볼은 바닥에서 포물선을 그리며 튀어오른다.

### 플레이어
- **이동:** 좌/우 이동만 가능. 점프 없음.
- **공격:** 와이어 샷(Harpoon) — 위쪽으로 수직 발사. 천장에 닿을 때까지 재발사 불가.
- **사망:** 어떤 크기의 볼이든 닿으면 즉사, 스테이지 처음부터 재시작.

### 스테이지 클리어 조건
화면 내 모든 볼을 제거하면 클리어.

---

## 파워업 아이템

스테이지 진행 중 볼 처치 또는 화면에서 드롭된다.

| 아이템 | 효과 |
|-------|------|
| Double Wire | 와이어 2발 동시 발사 가능 |
| Power Wire | 발사한 와이어가 천장에 붙어 일정 시간 장벽 역할 |
| Vulcan Missile | 고속 연사 |
| Force Field | 볼 접촉 1회 무효화 |
| Clock | 볼 이동 일시 정지 |
| Dynamite | 화면 모든 볼을 Tiny 크기로 즉시 축소 |
| Food | 보너스 점수 |

---

## 점수 시스템

- 볼이 작을수록(Tiny에 가까울수록) 더 높은 점수를 획득한다.
- 같은 크기의 볼을 연속 처치하면 점수 배율(멀티플라이어)이 상승한다.
- 스테이지 클리어 시 남은 시간에 비례한 보너스 점수가 지급된다.
- 특정 누적 점수 달성 시 1UP(추가 목숨)이 지급된다.

---

## 게임오버 조건

- 시작 목숨: 3개
- 볼에 닿으면 목숨 1개 차감, 해당 스테이지 재시작
- 목숨을 모두 소진하면 게임오버
